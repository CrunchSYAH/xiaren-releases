# 虾仁 · 印尼 Shopee 达人建联工具

独立实现的本地 Chrome Manifest V3 扩展，适配 `seller.shopee.co.id`。填写发送目标人数后，工具在专用达人页加载并排除本工具已有提交／待核对及拒绝记录；广场与排行榜额外准备约 10% 候选，默认勾选前目标人数，核对最终选择后运行串行队列。名单每页显示 10 人，右侧实时显示消息内容。

## 加载

1. 在 Chrome 打开 `chrome://extensions`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本项目的 `extension` 文件夹。
3. 点击扩展图标打开工作台，再点击“打开专用 Shopee 页”。页面登录并就绪后可直接准备名单，无需单独读取。

需要 Chrome 106 或更新版本；无需安装 Node.js 或执行构建即可加载扩展。扩展只声明本地存储、按需脚本注入、印尼卖家站权限，以及更新页读取 GitHub 正式版所需的四个发布域名；不申请全网站、Cookie、下载或原生程序权限。

更新源码后，在 `chrome://extensions` 找到本项目扩展并点击“重新加载”，再从工具栏重新打开工作台；只刷新工作台不会更新已加载的后台。若界面提示“扩展后台尚未更新”，按此操作处理。

### GitHub 安装包与更新

工作台侧栏“检查更新”打开更新页：读取 GitHub 最新正式版，发现新版本后可一键自动更新——下载 ZIP 与 SHA256、本地校验、解压并只覆写安装目录的 `extension/`，完成后自动重新加载扩展。首次使用需在更新页选择一次 extension 文件夹（句柄保存在本机，Chrome 122 起可持久授权）。更新页只做只读请求到 GitHub 发布地址，不上传页面、名单或消息内容。

正式发布包包含 `extension/`、`update.cmd`、`update.ps1`、`release.json` 和说明。首次完整解压到固定位置，在 Chrome 加载其中的 `extension/`。自动更新不可用时的手动兜底：在所有 profile 结束任务后，双击原安装目录的 `update.cmd`，输入 `UPDATE`；脚本从固定发布仓库下载最新版及 SHA256，校验路径、版本和权限后，将旧扩展移入 `backups/` 再部署新文件，失败会尝试恢复旧目录。随后在每个 profile 手动重新加载虾仁，重新打开工作台核对版本号。不要卸载扩展或改变加载路径。

需要发给不熟悉电脑操作的人时，改用一键安装包：`node scripts/package-installer.mjs` 生成 `artifacts/xiaren-installer-v<版本>.zip`，解压后双击 `install.cmd`。脚本会从 Chrome／Edge 各 profile 的 `Preferences` 里找出以“加载已解压的扩展程序”方式加载的虾仁目录，备份旧版后替换 `extension`，失败自动回滚；找不到记录时按首次安装装到 `%LOCALAPPDATA%\Xiaren` 并提示加载路径。该安装包与官方发布包分开维护，官方包内不放这些脚本。

更新脚本保留下载暂存与旧版备份，不自动删除。回退时先结束全部任务，将当前 `extension` 改名保留，再把对应备份复制为原位置的 `extension`，最后在每个 profile 重新加载。浏览器本地数据不包含在文件备份中，降级不保证兼容新版数据格式。

发布者先运行项目规定检查和正式 Node 测试，再运行 `node scripts/package-release.mjs`；脚本只收集正式扩展及分发脚本，版本须与 `package.json` 一致，已有同名发布包不覆盖。只向发布仓库上传该 ZIP、其 SHA256 和公开使用说明，不上传工作目录、私钥、测试产物或店铺数据。

筛选后的专用页加载完成时会自动重新连接；切回工作台立即刷新连接状态。若连接失败会显示原因，处理后点击“打开专用 Shopee 页”重试，原任务不会自动恢复发送。

## 使用

两个店铺分别登录不同 Chrome profile 时，在每个 profile 分别加载同一份 `extension/`，各自打开工作台即可独立运行；操作与验收见 [双店铺说明](docs/multi-store-profiles.md)。

1. 在工具创建的 Shopee 页面登录；分类和社媒可在工作台应用，粉丝等其他条件仍在 Shopee 页面设置。
2. 第一步编排 1–10 条文字、链接或图片消息，可新增、删除、重置和上下排序；文字最多 2400 字，支持 `{{name}}`；链接填写完整 HTTP/HTTPS 网址，以普通聊天文本提交。图片每条一张 PNG／JPEG、单张小于 2 MiB，可导入并预览，或复用本机已存图片。可填写任务名称（最多 80 字），逐人间隔默认10秒，右侧按顺序预览，默认真实发送。
3. 第二步选择达人广场、排行榜、指定联盟伙伴 ID 或指定已加载 Shopee 用户 ID，可填写姓名包含／排除条件。广场／排行榜目标默认100、允许1–200；两种指定ID独立保存，去重后人数即目标。切换广场或排行榜会在后台打开或导航对应专用页，不激活该页、不抢占工作台焦点；勾选“应用 Shopee 网页筛选”，选择真实页面提供的分类与社媒，再点“准备名单”，工具逐步应用并核对生效后才取名单。名单需要继续加载时，工具会主动显示专用页并提示保持可见；备齐后回工作台调整最终选择；候选缓冲与补足规则见下节。少于目标人数或无法核实不能启动，指定 ID 不以其他达人补齐。来源或条件变化须重新准备。
4. 核对最终已选名单与每条消息后，勾选发送确认，再启动真实发送；需要演练时主动切换为“演练”，演练不填草稿、不点击发送。内容、顺序、来源、名单、账号或文档变化会撤销确认。工作台每页10人仅改变展示；排行榜原站翻页由工具控制，每位达人的整组消息全部完成点击并保存后才记为已提交，再计算逐人间隔；组内连续调度，不额外等待固定轮询间隔，仍等待上一条草稿、附件预览清空，并逐条核对、授权及保存。逐人间隔是整组完成后的冷却时间，切换聊天和提交耗时另计。
5. 中断后先检查草稿及当前条结果；结果不明须“确认当前条已提交”或跳过该达人，确认只推进这一条，余下内容仍等手动继续，不重发已提交前缀。暂停／停止任务可继续，或结束后建立下一任务。左侧“任务记录”可按店铺、模式、状态、任务名称／关键词和日期筛选，查看消息顺序、来源与逐人结果并导出；查看历史无需连接 Shopee。

保持专用页面打开，运行时不要手动切换聊天、修改草稿、账号或名单。浏览器可能延后后台页面计时；工具不追赶补发，页面无响应时暂停。界面显示暂停/停止后，已触发的发送仍可能完成，无法撤回。

## 候选与勾选

- 广场／排行榜的发送目标 N 为 1–200，候选目标为 `min(200, N + ceil(N / 10))`。目标 100 人时准备 110 人、默认勾选前 100 人；目标 200 人时没有额外缓冲。指定用户／联盟伙伴 ID 和达人库选择仍精确准备，不补其他人。更新前已锁定的旧名单保持原规则，需取消并重新准备才能启用候选勾选。
- 取消勾选只影响本次选择，不加入拒绝名单。已选满 N 人时需先取消一人才能选另一人；跨页保留选择，最终处理顺序始终按来源页面顺序。任务开始后不能修改选择。
- “补足到 N 人”按候选顺序补入未被取消、仍可用的人，不自动勾回你取消过的人。取消 11 人但仅有 10 名备选时，只能补到 99／100，禁止启动；可手动勾回一人，或显式“继续加载候选”。继续加载每次增加约 N／10 的候选名额，最多 200 人，原选择保留；“恢复默认前 N 人”可显式清除本次换选。
- 页面正常耗尽时候选不少于 N、但不足缓冲目标，可用现有候选继续选择；候选少于 N、加载无法核实或超时则阻止启动。每次换选／补足／重置会撤销发送确认，只有恰好 N 人通过预览核对才能启动；未选候选不会进入队列、任务记录或防重发历史。

## 排行榜、指定伙伴与本地达人库

- 排行榜：选择来源后专用页自动跳转；榜单和周期仍在 Shopee 页选择，分类与渠道可在工作台应用。默认从第一页准备，或勾选“从当前位置准备”从当前页起向后获取。工作台仅提供分类与渠道，Popular 榜没有分类时禁用该控件。按真实行序与 Shopee 用户 ID 去重保留首次位置；锁定榜单条件和每页整份名单，处理时受控定位原页并同步核对。准备及处理期间不得手动翻页或改筛选。
- 当前位置：达人广场从点击准备时屏幕内第一位可靠可见达人起，排行榜从当前页起；继续排除已提交、待核对及拒绝记录。广场仍核对已挂载的完整前缀，不支持虚拟行回收。若本次应用筛选重置了页面位置，工具先提示重新定位，再次点击准备才取名单。队列下方同样每页显示10人，翻页不改变发送顺序；出现待核对项可点击按钮定位。
- 指定联盟伙伴：输入1–200个联盟伙伴ID，点击打开专用页后准备。逐个通过官方详情精确核对联盟伙伴ID、Shopee用户ID及当前店铺；按输入顺序锁定，不用同名或数字相等猜映射。处理时再次导航目标详情，绑定新文档和会话；只有已落盘的受控导航可续接，人工导航、错误文档、权限不足或映射变化都会阻止。原“指定已加载Shopee用户ID”仍只筛选广场挂载行，两种ID不可互换。
- 本地达人库：左侧同标签页打开，往返保留工作台草稿，支持手工添加、JSON／CSV导入导出、搜索筛选、标签和备注。最多2000条、JSON UTF-8总量2MiB，全库版本冲突拒绝覆盖，不自动删除。手工和导入身份均待页面核实，库不提供云端数据或聊天可达保证。选择同店铺已有Shopee用户ID记录后回到工作台，显式“套用达人库选择”只改名单并撤销确认，保留消息；仍须在专用广场重新准备。无可靠用户映射的伙伴ID记录不能直接套用发送。

## 消息模板

在任务设置上方填写“模板名称”，将下方完整消息序列“存为新模板”。已有模板可改名并“保存修改”，也可“复制已存模板”；复制以已保存内容为准，自动生成不重名的副本名称。

选择模板后点击“套用”才会替换当前消息类型、内容和顺序，并更新逐条预览、撤销原发送确认；仅选择、保存或复制不会覆盖草稿。模板不保存店铺、达人名单、人数、逐人间隔、模式或确认，真实发送仍须重新核对；已有任务未结束时不可套用或修改模板。准备名单期间仍可编辑消息或套用模板。

模板仅保存在本机，最多 50 条、存储 JSON UTF-8 总量 512 KiB；名称最多 50 字符且不能重名；每条文字最多 2400 字符，链接最多 2000 字符；图片在模板中只保存引用，复制模板共享同一图片原件。旧话术加链接模板仍可套用，显式保存时才写入新版消息序列。多窗口同时编辑同一模板时，后保存的旧版本会提示刷新，避免覆盖他人的修改。保存失败保留草稿与原模板，可处理原因后重试；本轮不提供模板删除或导入。

图片原件独立保存在本机，最多 20 张、图片存储 JSON 总量 4 MiB；相同图片按内容摘要去重，满时拒绝新增，不自动删除旧图。导入失败保留原图片，缺图或解码失败时不能启动含图任务；图片必须先落盘、成功解码并核对尺寸才能用于任务。任务及历史导出只含图片引用和元数据，不包含图片原件，不能作为完整图片备份。

## 数据与边界

- 名单、话术、产品链接、拒绝名单、状态和防重发历史只保存在扩展本地存储；不采集 Cookie、密码或访问凭证，不向厂商服务上传数据。
- 按店铺与达人稳定标识去重；换话术或切换演练/真实模式不会绕过去重。切换账号、导航、列表被替换或重排会使准备失效并暂停旧任务，不能在另一店铺恢复旧任务。
- 一次只运行一个任务，目标最多 200 人，每人最多 10 条消息。收集依据本工具历史，不承诺覆盖在其他工具或人工操作中的联系记录，也不代表平台许可额度。
- 去重记录不会自动删除。卸载扩展、删除本地扩展数据或换 Chrome 用户配置会丢失记录，使用前通过工作台导出任务结果并自行保管。
- 任务记录与防重发索引分别保存：当前任务始终可查询；建立下一任务前先将旧结束任务归档，旧版本已被覆盖的任务无法补回。归档最多 100 条、JSON UTF-8 总量 3 MiB，不自动删除；容量满或归档失败会保留旧任务、阻止本次新建。记录包含配置与逐人结果，不包含页面绑定和执行授权；历史页不提供删除、重发或恢复任务入口。
- 工作台左侧“导出排查日志”可下载 JSON，用于排查中途暂停；没有日志面板。记录任务/逐人状态变化、暂停与恢复、已知具体错误、超时耗时及页面可见性/联网状态，恢复、结束或新建任务后仍保留；最多保留最近 3000 条，另设约 1 MiB 保守容量上限，超限淘汰最旧记录并记录淘汰数。
- 排查日志独立保存在本机，不记录消息正文、达人/店铺身份、页面内容、URL、凭证或堆栈；未知异常只导出错误类型，避免任意异常文本泄露信息。日志异步保存，失败或延迟不阻塞发送、不触发重发；导出包含当前任务摘要、扩展/浏览器版本、时区及日志保存状态，导出本身不重连、不使队列超时或恢复发送。更新扩展前发生且未记录的暂停无法补回。
- 页面内部结构可能变化；无法识别店铺、达人、收件人或发送控件时会阻止发送/暂停。发送意图和页面点击不是一个原子操作，不能承诺绝不重复或绝不漏发。
- “已提交”只表示工具核对后完成本任务该达人的全部发送点击，不证明平台接受、送达或已读。工具不再读取聊天消息、历史消息编号或回执；首次聊天也无需历史基线。点击后平台异步拒绝、网络失败或其他延迟异常不再自动识别，需在专用页面查看。更新前已建立的单／双消息任务保持原配置，不会自动追加或重排消息。
- 每条消息点击前在同一同步页面操作内复核店铺、收件人、当前已绑定文档及来源锁：广场核对原名单前缀并允许追加，排行榜精确核对目标页整份名单和筛选，指定伙伴核对官方详情完整映射；任何目标移除、重排或入口变化都阻止。每条提交声明先保存、单独授权，均只允许一次点击；点击返回或提交结果保存失败时停止推进并保留防重发记录。下一条发送前不会强制清空或覆盖尚未清空的草稿或附件。图片先进入原站本地预览，核对同一文件、尺寸及会话后才可授权；最终图片令牌在 MAIN 中只消费一次，回包或结果保存不明时不补选、不重试。

广场支持已核实的追加式列表；排行榜仅支持当前每页20人、最多200名的普通替换式分页，未知分页或虚拟行回收拒绝适配。当前不包含云端达人库、跨站点、多店铺并行、定时无人值守、视频或自动追发。图片当前适配已核实的“先本地预览、再点击发送”页面版本；上传入口、成功回调或发送处理器变化时会阻止图片操作。真实平台发图尚未验收；非发送检查仅验证选图、文件引用与取消，不能证明上传成功或送达。
