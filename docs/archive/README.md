# 历史归档

这里存放**已完成、已被取代、仅作追溯用**的开发记录。正常开发不需要读；排查历史决策、
复盘某次改动为什么这么做时才来翻。

`docs/` 根目录只保留当前仍然有效的说明文档：`active-work.md`、`local-testing.md`、
`multi-store-profiles.md`，以及进行中的 `tasks/`。

## 分类

| 目录 | 内容 | 时间跨度 |
| --- | --- | --- |
| `verification/` | 逐次功能验证记录（`verification-*.md`）、验收评审与证据 JSON（`acceptance-*`、`*-evidence-*`）、专项排查（`investigation-*`、`req4-*`） | 2026-10-15 ~ 10-22 |
| `plans/` | superpowers 工作流的历史实施计划，一功能一份 | 2026-10-15 ~ 10-21 |
| `handoff/` | 阶段交接说明：达人库、排行榜接入、指定伙伴 | 2026-10-20 ~ 10-22 |
| `design/` | 已落地功能的设计与改版记录：MVP 需求、目标人数集成、筛选器 UI、0.1.3 变更清单 | 2026-10-15 ~ 11-11 |
| `research/` | 竞品插件研究与来源并行调研，含采集截图目录 | 2026-10-19 ~ 10-21 |
| `screenshots/` | 工作台界面视觉证据（筛选器宽/窄版、队列分页） | 2026-10-21 |
| `sdd/` | 早期 SDD 工作流的任务简报、报告与评审包 | 2026-10-15 |

## 使用约定

- 归档文件**不再修订**。发现内容过时就补一句"已被 X 取代"，不要在原文件上改结论。
- 验证记录描述的是**当时**的行为，不能当作当前版本的事实——当前行为以 `extension/` 源码、
  `tests/` 用例和 `AGENTS.md` 为准。
- 新增归档按上表归类；没有合适类别时新建目录并在此登记一行。
