# 印尼 Shopee 达人私信工具：第一版规格草案

日期：2026-10-15

## 已确认与待确认

- 已确认：印尼站、电脑端 Chrome、达人站内聊天、自动队列发送，异常时暂停。
- 当前授权：用户于本聊天回复“继续”，按本规格推进第一版开发及非发送验证。选择自动队列及批准开发不等于授权现在向达人发送消息。
- 开发验证使用本地模拟与新建标签页的页面检查；真实发送验收仍需用户另外授权。
- 名单入口暂按“从达人广场当前可见列表选择”设计；发送间隔、任务上限由启动前设置，不预设所谓安全条数。

## 实现方向

独立实现 Chrome Manifest V3 本地扩展，以 Shopee 当前登录页面完成操作。第一版只适配 `seller.shopee.co.id`，不依赖虾秘厂商账号、会员、服务或代码。

自动队列由用户明确启动，在单个专用标签页中串行执行。每位达人只允许一次发送尝试，确认结果后才进入下一位；结果不明则暂停核对。

当前未证实存在可直接采用的公开达人聊天发送 API，因此不把官方商品佣金活动接口或买家客服接口当作本工具的发送通道。

## 第一版范围

1. 在工具自建的达人广场标签页读取当前可见列表，由用户选入名单；不自动翻页采集全站达人。
2. 提供一个纯文本模板，支持已读取的达人名称；预览逐人展开后的内容，空文本、缺失变量阻止启动。
3. 按当前店铺和达人稳定标识做去重，支持拒绝名单；换模板不绕过已联系记录。
4. 显示队列、当前达人、成功、跳过、失败和待核对状态，支持暂停和停止。
5. 保存本地任务记录，支持启动前预览及导出结果；不上传名单、模板或日志。

启动前必须可靠识别当前店铺、每位达人的稳定标识和可操作的列表行；任意一个无法核实时不允许发送。显示名不作为唯一标识。

## 完整执行流程

1. 用户在专用标签页选入达人，编辑模板，设置发送间隔及本次任务上限。
2. 工具显示店铺、去重后的名单、跳过原因及逐人消息预览；用户点击“启动队列”。
3. 工具复核当前店铺及页面状态，取得唯一执行权，持久化本次任务配置快照。
4. 选取下一位待处理达人，再次检查拒绝名单、历史记录和当前页面身份。
5. 打开对应聊天，核对收件人及完整文本，确认输入框和发送按钮可用。
6. 在持久化记录发送意图后，才允许触发一次发送；同一任务项不得自动再次点击。
7. 核对当前聊天中新出现、属于本次操作且与目标文本匹配的发出消息；存在发送中或失败标记时不能认定成功。仅凭输入框清空或按钮消失不能认定成功。
8. 证据充分才标记成功；随后按设置等待，再处理下一位。不能确认、发生异常或用户暂停时停止推进。

任务启动后不在线修改名单和模板。修改配置须暂停、完成当前项核对并重新预览，再更新配置快照和执行会话，避免队列后半段内容与启动时不一致。

## 异常与恢复

- 登录失效、店铺切换、风控提示、验证码、聊天对象不符、页面结构变化、操作超时或发送失败：暂停整个队列并显示原因。
- 已联系、重复、拒绝名单和超出本次上限的达人：发送前跳过，记录原因。
- 已记录发送意图但未获得可靠结果：标记“待核对”，不自动重发；人工检查后可标记已发送或跳过。
- 浏览器关闭、专用标签页关闭、扩展重载或无法核对的执行中断：不自动恢复发送。下次打开先检查未完成记录，再由用户明确恢复。
- 暂停或停止会阻止后续发送；已触发的发送无法撤回。当前项如仍在执行，界面须显示“正在停止，核对当前结果”。

暂停发生在点击发送前时，当前项仍须确认未触发发送，才能保留为待处理。无法确认时统一进入“待核对”。

## 状态与数据

- 任务状态：草稿、运行中、暂停中、已暂停、停止中、已停止、已完成。
- 达人状态：待处理、准备中、发送中、已发送、已跳过、已失败、待核对。
- 队列记录：任务标识、执行会话标识、店铺标识、达人标识、名称、展开后的文本、状态、时间及错误原因。
- 去重记录按店铺隔离；发送中及待核对项同样阻止新任务再次发送，必须先人工核对。
- 一个扩展实例同一时间只运行一个任务；重复启动、多个面板或旧页面返回的消息不得推进当前任务。

发送意图与实际点击之间无法实现跨浏览器页面的原子事务，因此第一版不承诺绝对的“恰好发送一次”。恢复策略偏向暂停核对，避免崩溃后盲目重复发送。

## 模块边界

- 面板：名单选择、模板预览、配置、队列进度及用户控制。
- 队列控制：持久化状态、串行派发、去重、任务互斥和中断恢复。
- 页面适配：读取列表、打开并核对聊天、填入文本、单次发送及结果证据。

Manifest V3 后台可能正常休眠，不能依靠后台常驻或仅存于后台内存的计时器保存任务。专用页面每次只执行一个明确指令；页面在等待结束后请求下一步，后台唤醒后读取持久化状态，核验原标签页、执行会话和当前任务项，全部一致才继续响应。

普通后台休眠本身不要求人工恢复；无法确认原执行会话、存在未核对发送意图或标签页重建时则暂停，不能重新派发旧发送指令。页面等待受浏览器节流影响，实际间隔可能更长，但不得为追赶进度连续补发。

## 权限与凭证

- 网站权限限定印尼卖家站，其他权限仅按实际功能添加，不申请全网站访问。
- 不读取、导出或保存 Cookie、密码、token、厂商凭证；通过页面正常使用当前登录会话。
- 任务数据保存在扩展本地存储，日志不记录完整页面响应、请求头或凭证。
- 不修改原安装扩展，不操作用户原有标签页，不绕过厂商付费、平台验证或聊天限制。

## 验证与验收

1. 用本地页面夹具和模拟时钟验证正常队列、间隔、上限、去重与模板展开。
2. 验证登录失效、目标不符、缺失控件、输入框清空但没有消息证据等情况均暂停且不误报成功。
3. 验证双启动、旧会话回报、暂停与发送交错、关闭页面及异常中断不会自动重发或启动下一位；普通后台休眠后须通过会话校验才能继续。
4. 在新建的 Shopee 标签页验证真实页面读取与目标定位；发送前先使用不点击发送的演练模式检查完整流程。
5. 真实发送验收另需用户明确指定测试达人并授权；未授权前只报告模拟与演练结果，不宣称真实发送已验证。

## 不纳入第一版

- 厂商云端达人库、会员服务及历史数据迁移。
- 多站点、多店铺并行、无人值守定时启动。
- 图片、附件、多轮自动回复及自动追发。
- 验证码处理、规避平台风控、所谓保证安全的每日发送额度。
- CSV 导入与大规模自动采集；先验证当前页面名单到聊天发送的完整链路。

## 开发边界

按“从当前可见达人列表选择名单”的入口实现第一版。若真实页面无法可靠提供身份或发送结果证据，界面应说明具体原因并禁用发送，不用猜测值降级执行。
