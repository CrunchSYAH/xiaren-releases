# 本地 Chrome 插件测试环境

**目标：** 用户在本地模拟店铺测试实际 Chrome 插件，无需在真实店铺运行任务。

**方案：** 正式 `extension/` 保持不变，生成独立的 `artifacts/extension-local-test/`。测试版沿用相同队列、后台与内容脚本，仅替换允许访问的来源、专用页地址和界面提示。使用现有真实页面结构契约构建虚构店铺，不保存真实账号或会话，不将普通网页快照误称为可完整重放的网站。

**边界：** 测试版权限只有本机，代码限制 4177 端口；正式版继续只有印尼站权限。本地页面限制外部请求。测试通过不能证明平台真实发送成功，不安装或更改用户现有扩展，不提交或创建分支。

- [x] 验证生成包、静态服务器边界与页面交互，运行原有测试及语法检查。

最终证据：61/61 自动测试通过；10 个文件、2 段夹具脚本及生成测试版语法检查通过；正式插件 10 个文件与上一版包哈希一致；独立只读审阅通过。已在浏览器核对本地场景及演练零点击，未把测试版实际安装到用户 Chrome，真实扩展层交互由用户按指引加载验收。本轮没有访问或测试真实店铺。
