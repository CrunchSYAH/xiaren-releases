# 真实页面脱敏离线样本

**Goal:** 用真实页面的脱敏布局、节点层级与必要运行状态替换手写测试页入口，记录离线检查能够及不能证明的结论。

**Architecture:** 在工具自建的 Shopee 标签页采集，浏览器内先脱敏再导出。快照只保留允许的 DOM 属性、计算样式及白名单 React 属性链；移除原脚本、事件、资源地址和用户内容。离线重放机械恢复采集的属性链，原样运行生产页面检查函数；后续点击、回执与故障变化由明确标记的本地测试替身提供，不冒充真实状态。

**Constraints:** 不写入草稿、不发送、不修改用户原标签页、不保存凭证；生产扩展不放行本机；没有实际采到的历史消息或网络状态不编造为真实样本；不提交或创建分支。
