# 网页筛选与当前位置准备实施记录

> 2026-10-22 更新：用户在需求4中确认删除工作台“Shopee 达人名称搜索”。下文保留最初实现／实页核对的历史记录；当前公开筛选接口仅含分类与渠道，原页人工名称条件只读参与筛选锁。当前行为及兼容验证见 `docs/req4-search-removal-2026-10-22.md`。

**目标：** 在选择达人页应用 Shopee 的分类、社媒与名称搜索，选择排行榜自动切换专用来源页，队列每页显示 10 人，并支持用户已确认的当前位置起点。

**边界：** 正式扩展无构建或新增依赖；只操作已有专用顶层页。筛选和准备不触发发送；保留锁定名单、店铺、文档、逐条提交及防重发核对。不创建分支或提交，不生成或安装已暂停的本地测试插件。

## 实现划分

- [x] 页面适配：独立同步 MAIN 筛选读取/动作函数；选项来自真实页面控件；每步最多改变一个条件，下一轮重新核对。排行榜无搜索则明确禁用。快照携带筛选上下文和可靠的视口起点。
- [x] 集合模型：source 可选 webFilters 和 startPosition；广场保留整份挂载前缀，仅从固定可见锚点筛选；排行榜保留完整逐页核对，允许当前页起步。筛选上下文改变使名单失效。
- [x] 工作台：真实选项、异步响应隔离、来源自动导航、当前位置选项；队列独立分页，不改变调度和逐条人工核对。
- [x] 后台集成：筛选准备先持久化再逐步应用；全部条件与店铺/文档核实后建立集合；取消/导航/超时后不继续。当前位置且筛选有变化时先应用，提示重新定位后再点准备。
- [x] 验证：先新增行为测试确认失败，再实现；跑相关测试、项目允许的全部 Node 测试及 scripts/check.mjs；读取全部改动并独立审查。

## 接口

`panel:filters` 只读取当前专用页面筛选，返回 `pageFilters`，含 `supported:{category,channel,search}`、`current:{category,channel,search}`、`options:{categories,channels}`、`path`、`documentEpoch`。选项为 `{value,label}`，value 均为字符串。

`panel:collect` 的 source 可选 `webFilters:{category,channel,search}` 和 `startPosition:'current'`；省略字段保留旧流程。筛选异步阶段在 `workspace.preparation` 中显示；只在核对完成后创建 `workspace.collection`。
