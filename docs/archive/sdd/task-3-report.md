## 交互与接口

- `chrome.runtime.sendMessage({type,...})` 对接全部简报 `panel:*` 接口；读取失败可显示后台中文原因，响应含 state/workspace 时统一吸收。额外按主代理说明，为真实发送启动传入 `confirmed:true`。
- 每 1.5 秒读取一次后台；进行交互请求时跳过新轮询。名单、队列及拒绝名单使用按达人 ID 保留的 DOM 行，未变化文本不赋值，预览选项只在选项修订时更新；输入与勾选不被普通轮询覆盖。
- 默认演练、模板空、间隔空、上限空、名单不选；校验正数间隔、正整数上限、200 人上限、2000 字模板和唯一支持的 `{{name}}` 变量。
- 配置、名单、拒绝名单、连接与名单数据修订使预览令牌及真实发送确认失效；真实发送必须先生成有效预览并勾选确认。包含断连过渡的店铺变化会清除选择，提示重新读取名单。
- 当前任务未结束时固定配置；暂停、停止提供继续和结束入口。不确定项必须先人工核对，继续/结束按钮均禁用；失败项明确说明继续时跳过。导出原始 task/denied 数据，不把演练转为真实发送。

## 自审与修正

- 对照后台实际 `core/backend.mjs` 与 `core/queue.mjs` 追踪预览、启动、恢复、结束和核对字段，未发现当前接口形状冲突。
- 修正跨断连换店铺遗漏：保留最后已知店铺 ID，识别 A → 断连 → B；当前任务来自另一店铺时不把旧任务名单勾选到新店铺列表。
- 区分“暂停/停止”和“已结束”；未结束任务不能修改模板或启动新任务，结束保留后端历史。恢复要求当前店铺与原任务一致。
