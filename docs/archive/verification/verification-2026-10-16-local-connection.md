# 本地测试无法读取店铺：修复与验证

## 根因与修复

用户反馈“无法读取店铺”。在已安装的仅本机测试版中复现：店铺与名单为空，工作台最终提示“原页面文档已变化，请重新连接并核对”，反复读取无法恢复。

Chrome 的标签页 `complete` 事件先于重放模块完成异步样本读取。现场记录：`document.readyState` 已是 `complete`，但 `__recordedReady` 为 `false`，首次快照的店铺为空；稍后样本就绪，快照能返回 `sample_shop` 和 12 位达人。

后台首次握手先校验店铺，校验失败后没有保存当前文档的有效时间基准；后续读取把同一文档的时间基准与空值比较，错误地判断为文档变化。此问题也会影响真实页面异步加载店铺身份的相同路径，未在真实店铺验证。

经用户在本对话明确授权跨越原先的文件分工后，仅调整 `extension/core/backend.mjs` 的读取顺序：先验证并在首次握手时保存当前文档时间基准，再校验店铺及页面。页面身份未知时仍拒绝任务操作；后续读取仍须匹配原文档与时间基准，并通过全部店铺、名单、控件与回执校验。
