# 消息模板管理验证 · 2026-10-19

## 交付

任务设置内新增消息模板区，支持命名保存、改名/更新、复制与显式套用。模板只存名称、话术和产品链接；选中、保存或复制不会自动覆盖当前草稿，套用后更新两条预览并撤销发送确认，保留店铺、名单、人数、间隔和模式。

数据、界面与独立验证三条线并行，主代理统一集成和验收。未修改发送状态机、页面执行器或同步点击逻辑，未增加权限、外部依赖或网络请求；未实现任意多消息编排。

## 存储与兼容

- 独立键 `creatorMessageTemplates`；缺少旧键时只返回空列表，不写入默认值。旧任务与任务历史不迁移、不改写。
- 最多 50 条、存储 JSON UTF-8 总量 512 KiB；名称最多 50 字符，按去空白和小写比较避免重名；话术与产品链接各最多 2000 字符。
- 更新与复制校验源版本，更新递增版本；复制保存的原内容并生成不重名的副本名，不复制当前未保存草稿。容量不足、版本冲突或写盘失败保留原值，不自动清理。
- 模板接口在业务初始化前校验工作台来源，只读取/写入自己的存储键；不初始化会话、不执行过期/重连/页面核对/注入/发送，也不记录或刷新诊断日志。模板失败不设置业务存储故障；原业务故障仍保留。

## 使用与范围

在 Chrome 重新加载“虾仁”，再从工具栏重新打开工作台，任务设置上方即可看到“消息模板”。填写名称、话术与产品链接后保存；选择已有模板后点击“套用”，核对预览并重新确认真实发送。未结束任务期间模板写入和套用锁定，准备名单期间仍可编辑内容。

所有修改留在工作区，没有新建分支、提交或推送，没有向真实达人发送。下一阶段如扩展任意多消息编排，需要单独设计逐条授权、部分提交与恢复语义。
