正在读取当前版本

先在所有店铺结束当前任务，再更新。更新会替换扩展文件。

  1. 打开 GitHub 最新版本，查看版本号和更新说明。
  2. 首次安装：下载 ZIP，解压到固定目录，在 Chrome 扩展管理页加载其中的 extension 文件夹。
  3. 以后更新：在原安装目录双击 update.cmd，从 GitHub 获取新版。脚本会先备份旧版，再替换 extension 文件夹。
  4. 在每个 Chrome profile 打开 chrome://extensions，找到虾仁并点击“重新加载”，再重新打开工作台核对版本号。

Chrome 本地扩展需要手动重新加载。请保持原安装路径，不卸载扩展，以保留该扩展的本地数据。
