手动更新（自动更新不可用时）
  1. 打开 GitHub 最新版本，下载 ZIP 与 SHA256。
  2. 在原安装目录双击 update.cmd，输入 UPDATE；脚本会先备份再替换 extension 文件夹。
  3. 在每个 Chrome profile 打开 chrome://extensions，找到虾仁点击“重新加载”。

自动更新只替换安装目录下的 extension 文件夹，不改动 update.cmd、update.ps1 等启动脚本。
